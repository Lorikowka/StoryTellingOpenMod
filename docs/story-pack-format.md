# Сюжетные пакеты: формат 1

Старые сценарии `ST/scripts/900051.lua` работают без манифеста. Их импорт через `require("characters.guide")` ищет файл в `ST/scripts/characters/guide.lua`.

Пакет размещается в `ST/scripts/packs/<id>/`. В корне пакета лежат `storypack.json`, перечисленные в нём числовые Lua-сценарии и каталоги библиотек Lua. Каждый сценарий пакета использует свой каталог пакета для `require`; чужие пакеты и общие файлы через него недоступны. Пример находится в `examples/story_scripts/packs/demo/`.

```json
{
  "id": "demo",
  "version": "1.0.0",
  "api": 1,
  "stories": ["900052.lua"]
}
```

`id` совпадает с именем каталога: латинская строчная буква, затем до 63 строчных букв, цифр, `_` или `-`. `version` записывается как `major.minor.patch`. `api: 1` означает текущий Lua API с `story`, `part`, `npc` и существующими действиями. Другие версии API отклоняются. `stories` перечисляет хотя бы один файл вида `<положительное девятизначное или более короткое число>.lua`; путь и повторения запрещены. Размер манифеста ограничен 64 КиБ. ID сценария должен совпадать с именем файла и быть уникальным среди Java-сценариев, старых Lua-файлов и всех пакетов. При конфликте первый зарегистрированный сценарий сохраняется; `/script validate` сообщает о конфликте.

Поле `dependencies` в формате 1 можно опустить или задать пустым массивом. Непустой список отклоняется: загрузчик пока не разрешает зависимости между пакетами. Файлы моделей и текстур пока читаются через общий `ST/assets/`; каталог ресурсов внутри пакета и права доступа к игровым действиям в формат 1 не входят.

Проверка синтаксиса, манифеста, ID и объявлений говорящих: `/script validate`. Для `speech(1, ...)` нужно объявление `speaker(1, ...)` или `npc:speaker(1)`; действия в мире команда не исполняет. Загрузка всех определений: `/script reload`. Перезагрузка одного файла: `/script reload packs/demo/900052.lua`; файл должен быть в списке `stories`. Изменение библиотеки пакета становится доступным после перезагрузки использующего её сценария. Уже работающий экземпляр сценария продолжает прежнее определение. Изменение манифеста требует общего `/script reload` для обновления списка сценариев; выборочная команда не удаляет старый зарегистрированный ID.

Пакеты пока являются локальными доверенными файлами автора. Ограничения времени и памяти Lua, права на игровые действия, зависимости, установка архивов и миграция сохранений для будущих версий API остаются отдельной работой.
