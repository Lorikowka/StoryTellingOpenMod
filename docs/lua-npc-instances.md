# Шаблоны и экземпляры NPC

Lua-модуль может вернуть таблицу с `model` или `type`, именем и размером модели. `npc_instance(template, key, [name])` создаёт отдельный NPC из этой таблицы. Повторный вызов с другим ключом создаёт второго персонажа; исходная таблица остаётся прежней. Пример: `examples/story_scripts/900053.lua` использует `characters.guide` дважды.

```lua
local guide = require("characters.guide")
story(900053)
local first = npc_instance(guide, "guide_a", "Первый проводник")
local second = npc_instance(guide, "guide_b", "Второй проводник")
part("main")
first:spawn(0.5, -60, 8.5)
second:spawn(3.5, -60, 8.5)
```

Ключ экземпляра уникален внутри одного сценария. Его постоянный идентификатор в мире имеет вид `lua_<story_id>_<key>`; поэтому `guide_a` и `guide_b` получают независимые контроллеры и позиции. После сохранения мира и перезагрузки сценария ключ нельзя менять без потери связи с прежним NPC. Старый `npc(template)` продолжает брать `key` из таблицы и сохраняет прежний идентификатор. Для уже записанных сюжетов миграция не требуется.

Необязательное имя экземпляра меняет видимое имя NPC и говорящего. `model`, `type`, `width` и `height` берутся из шаблона. Для экземпляров в разных сценариях ключ может повторяться: ID сценария входит в постоянный идентификатор. Долговременное состояние персонажа помимо сущности и позиции будет отдельным этапом.
