# Игровая проверка alpha.50–alpha.52

Проверка выполнена в `runClient` на прежнем одиночном мире `New World` 14 ноября 2026 года. Результаты действий в интерфейсе подтверждены пользователем; технические ошибки сверены с журналами запуска.

| Участок | Результат |
| --- | --- |
| Запуск и `/script validate` | Клиент вошёл в мир; проверено 33 Lua-файла, ошибок нет. |
| `/storyedit`, `/storyblocks` | Оба экрана открываются. Сохранение и экспорт пока не проверены в игре. |
| `900031` | Пролёт камеры к NPC и возврат сработали. |
| `900032` | Lua-объект NPC появился и выполнил действия. |
| `900033` в alpha.50 | Ошибка `SpeechMessageAction`: не объявлен говорящий с ID 0. |
| `900034` | Ожидание двух яблок и финальная реплика сработали. |
| `900033` в alpha.51 | После добавления говорящего сценарий и завершение квеста сработали. |
| Старое сохранение в alpha.51 | Сообщения Forge об отсутствующих `storytelling:key` и `storytelling:eidos_item` исчезли после возврата ID. |
| `/quest` в alpha.52 | На присланном снимке видны завершённый квест, описание и отмеченная задача. Точное оформление будет уточнено по образцу пользователя. |

В журнале alpha.50 есть запись о восстановлении NPC `lua_900030_guide` из сохранения. Выбор и движение после перезахода требуют отдельной проверки. Также остаются игровая проверка перезагрузки одного файла, сохранения редактора, экспорта блоков и переключения вкладок журнала.
