# Очистка наследия: первая группа

`alpha.46` убирает 15 встроенных Java-глав: шесть старых сюжетных/отладочных `S1`, `S2`, `S3`, `S4`, `S7`, `S1111` и девять классов из `script/instances/test/`. Поиск по Java-коду не нашёл обращений к этим классам извне их собственных файлов. Также убраны два сценария, которые мод прежде автоматически копировал из JAR (`s7.lua` и `900001.lua`). Теперь `ST/scripts/` при первой установке остаётся пустой; уже созданные пользовательские файлы мод не удаляет.

Сохранения удалённых Java-глав не стираются при очередном сохранении мира. Движок удаляет сохранение только завершённого сценария, который всё ещё зарегистрирован. Это оставляет возможность вернуть старую главу из Git-истории без потери её сохранённого состояния.

Оставлены 14 служебных Java-сценариев в `script/instances/backs/`: они связаны с механиками мира и мини-играми. Их перенос требует отдельного анализа вызовов и сохранений. Файлы ресурсов также оставлены: сейчас в `assets/storytelling/` около 3 718 Bedrock-файлов (из них 3 622 анимации), 1 182 текстуры, 737 звуков, 241 модель и 111 blockstate. Пути к части файлов строятся во время работы, поэтому удаление по одному лишь поиску имени в Java-коде ненадёжно. Текстуры диалога и журнала квестов уже используются новым интерфейсом.

Следующий проход: составить таблицу регистраций предметов, блоков, сущностей и динамических загрузчиков Bedrock; затем удалять отдельные подтверждённо неиспользуемые группы ресурсов вместе с их регистрациями.
