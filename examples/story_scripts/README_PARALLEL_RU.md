# Параллельные ожидания в Lua (`alpha.89`)

Рабочий пример: `900063.lua`. После `/script reload` запусти `/script start 900063`, нажми F8 и дождись второй реплики. Два ожидания на 10 и 30 секунд идут одновременно; финальная реплика появляется примерно через 30 секунд. Если выйти в меню во время ожидания и вернуться, оставшееся время каждой ветки должно сохраниться.

```lua
story(900063)
part("main")
parallel_start("short_wait")
parallel_start("long_wait")
parallel_join("short_wait", "long_wait")
-- следующие действия выполняются после обоих ожиданий

part("short_wait")
wait_ticks(200)

part("long_wait")
wait_ticks(600)
```

Каждая ветка — отдельная `part` с уникальным ключом. Пока внутри неё разрешён только `wait_ticks`. Ветку можно запустить один раз; все запущенные ветки необходимо перечислить в `parallel_join`. В таком сценарии пока нельзя использовать якоря, `goto_anchor`, `var_if`, `/script goto` и `/script jump`.
